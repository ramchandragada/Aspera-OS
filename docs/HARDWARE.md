# Hardware

## Design target

**Intel Core i5 (4th generation) · 8 GB RAM · 128 GB SSD**

| Item | Minimum | Design |
|---|---|---|
| CPU | 64-bit dual-core ~2013+ | Core i5 4th gen |
| RAM | 4 GB | **8 GB** |
| Disk | 64 GB SSD | **128 GB SSD** |
| Firmware | BIOS or UEFI | both |
| Arch | amd64 | amd64 |

## Speed rules

- XFCE only
- zram on (50% of RAM)
- One browser
- Hub warm apps: 2–3, not five
- AnyDesk not running until needed
- SSD required for “blazing fast”
