# Branding

- `logos/aspera.png` — primary wordmark (docs / greeter)
- `logos/aspera-mark.png` — **start menu / panel only** (chevron mark, transparent)
- `logos/aspera-avatar.png` — user/account avatar
- `wallpapers/aspera-default.png` — default desktop (1920×1080 navy, small centered wordmark)

Do not put the full wordmark on the Whisker start button. Do not use a
full-bleed logo as the wallpaper.

Replace these files anytime; rebuild ISO or re-run Ansible branding role.
